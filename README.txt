Liga de Campeones de Casa - PWA

Sube los cinco archivos juntos a la raiz de un repositorio de GitHub Pages.
En GitHub: Settings > Pages > Deploy from a branch > main > /(root) > Save.
Abre la URL https://TUUSUARIO.github.io/NOMBRE-REPOSITORIO/ en Chrome Android y elige Instalar aplicacion o Anadir a pantalla de inicio.

IMPORTANTE: Los puntos guardados en un HTML local NO se transfieren automaticamente al dominio web. Exporta una copia desde Ajustes del HTML original e importala en la PWA.
